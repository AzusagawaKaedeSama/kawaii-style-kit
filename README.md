# 可爱风元素包 v003

视频《可爱风差在哪？》（Opus 5.5 的量化设计课 02）的配套资料。片子里不放数字，所有数字都写在这里。

```
components/
  candy.tsx          糖果字 CandyTitle：每一圈、每个字、字面渐变、高光都能单独控制（片中「一圈圈搭字」就是用它做的）
  candy_recipe.json  糖果字配方，以及仓耳舒圆体 W05 的逐字步进和高光坐标
  entrances.ts       两种入场：bounceEntrance（萌豚 · 弹进来）、smoothEntrance（丝滑 · 滑进来），共用同一张出场时刻表
  elems.tsx          绷带、针管、爱心贴纸、四角闪星、圆圈扩散、放大镜、定位容器
  motion.ts          弹簧预设 SPRING、压扁拉长 squash、关键帧 kf、标题落地 titleDrop
  theme.ts           配色：可爱风 + 地雷系
svg/                 四个元素的静态 SVG，外加一张糖果字示例（需要本机装有仓耳舒圆体 W05）
tools/
  candy-text.js      糖果字 SVG 生成器（R1 / R2 / R3），浏览器、Node、Remotion 都能直接用
  暗部占比.py         「够亮」检查：统计 L* < 30 的像素占比，并输出一张只保留黑色的高亮图
```

## 1 字：糖果字（萌豚系的多圈描边）

从里到外依次是：字面 → 白内圈 → 深色细线 → 浅色厚圈 → 白外圈。下表的宽度以字号（em）为单位，从字边往外量，每一圈的 `stroke-width = 2 × 累计宽度`。

| 圈 | 自身宽 | 累计 | 颜色 | 作用 |
|---|---|---|---|---|
| 字面 | — | — | 竖向渐变，上 `#FF80BD`、下 `#F8428F` | 上浅下深；不用斜纹 |
| 白内圈 | 0.070 | 0.070 | `#FFFFFF` | 把笔画之间的缝填白 |
| 深色细线 | 0.020 | 0.090 | `#B8326E`（L* 44） | 全字唯一的暗，所以只给一道细线 |
| 浅色厚圈 | 0.060 | 0.150 | `#FFB6D6`（L* 82） | 厚度在这一圈 |
| 白外圈 | 0.060 | 0.210 | `#FFFFFF` | 最外一圈永远是白 |
| Longshadow（R2） | 8 层 × 0.011 | — | `#D84F92` | 伪 3D 厚度，用深粉，不用黑 |

- 所有描边都用 `stroke-linejoin: round`。描得越多，拐角越圆，这正是「越描越圆」的来源。
- 每个字配两团高光（一枚胶囊 + 一颗圆点），裁在字面以内。坐标见 `candy_recipe.json`。
- 字距 0.03em。片内小字号用 R1，也就是去掉投影的版本。
- 假名用 FOT-Yuruka Std UB + R1，宽度按可见字高 H 计：白内圈 0.060H、深线 0.020H、浅色厚圈 0.110H、白外圈 0.094H，字距 0.18H。字高低于 150px 时，深线改为 0.035H、白内圈改为 0.045H。

## 2 色：够亮

案例 P2（ノノカ）同一版式只改颜色，实测数据如下：

| 版本 | 观感 | L* < 30 的像素 | 去色后 |
|---|---|---|---|
| 粉彩 | 奶乎乎 | 0.23%，全部在线稿上 | 平均 L* 85.7，84% 的像素 L* ≥ 75 |
| 灰调 | 样板间 | — | 平均 L* 75.2，低饱和、中明度 |
| 深色 | 夜店（酷） | 60.9% | 底、月亮、云连成一大片暗 |

- 颜色决定味道：浅出甜，暗出酷。深色版做到位也好看，只是不甜；这一节讲的是「要甜」时怎么配。
- 亮不是艳，而是浅：底和装饰全部放在 L* 75 以上，饱和色只给小面积。
- 暗色只当线，不当面：L* < 30 的像素控制在 2% 以内，并且只出现在描边和五官线上。
- 粉彩版主色：底 `#B6DFF9`，月亮 `#FFF3BD`，字面 `#FF9CC6 → #F2457F`，星星 `#FFE27A`。

## 3 形：够圆（案例 P3 的圆角半径，单位 px，画布 1920×1080）

| 元素 | 直角版 | 圆角版 |
|---|---|---|
| 卡片 | 0 | 36（照片框 22，头像框 22） |
| 对话框 | 0 | 34（关闭钮整圆 18，按钮做成胶囊 28） |
| 标签 | 0 | 胶囊 29 |
| 对话气泡 | 方形，尖尾巴 | 四角 82；尾巴尖端是 13 的圆头，根部 10，尾巴长度不变 |

星星和爱心的尖角不算在「圆」里，画圈时不要圈到它们。

## 4 动：会弹（`entrances.ts`，两份入场各 3 秒、60fps，共用同一张出场时刻表）

**A 萌豚 · 弹进来**：先到位，再叠一段衰减的余震（和 AE 的 Motion Excite 思路相同）。

- 主标题：过冲 9.4% → 回落 3.5% → 再过冲 1.3%，0.53 秒停稳；变形顺序是拉长时瘦高、过冲时矮胖，来回两轮。
- 人物：0.74 秒起跳，1.20 秒落地；落地压扁到 0.90、拉长到 1.04、再压到 0.98，1.67 秒停住；锚点在 (50%, 92%)。
- 底色：两层彩色圆错开 0.07 秒扩散，形成错帧叠层。圆圈扩散只用一次，在标题到位那一刻。
- 停住以后还保持小动作：气球飘、星星一缩一放、人物呼吸。不用频闪，也不抽帧。

**B 丝滑 · 滑进来**

- 位移、缩放、遮罩用 easeOutExpo `cubic-bezier(0.16, 1, 0.3, 1)`；透明度和模糊用 easeOutQuint `cubic-bezier(0.22, 1, 0.36, 1)`。
- 位移只有 16–110px，靠前的层走得多（视差）；模糊 4–12px，先糊后清；零过冲。停住后整张从 1 慢推到 1.015。

经验来源：RemainVCL《关于弹与思路》提到「过冲不需要太强……但不能没有」「阻力（衰变）可以设一个较大的值」「锚点放在立绘中下」「竖扁到横扁，往复两个循环」。

## 5 地雷系（案例 P4，以超天酱的素材为主）

- 黑穿在身上，甜留在脸上。P4A 的暗像素（L* < 35）占全画面 15.0%，其中头发 35.7%、衣服 15.3%、线稿 24.3%、窗框和 UI 线 15.9%；两张脸和整片底都是亮的。
- 底：浅粉紫菱格 `#F3CBF1` / `#ECB9EE`（去色后亮度约 81–86%）。电紫 `#7340DA` 只出现在硬投影里。
- 纯地雷系常用配色：樱粉 `#FEB8C3`、深玫红 `#A33751`、近黑 `#262425`，再加白。
- 像素 UI：4px 网格、4px 近黑边 `#2E2A2E`、1 格高光、(8, 8) 电紫 40% 硬投影。像素画只能按最近邻整数倍放大。
- 地雷符号（绷带、药片、针管、爱心）离脸至少 40px。

> 数字要单独换字体：仓耳舒圆体的「2」像「Z」，「扣2」会读成「扣Z」。片里给 Yuruka 再注册一个只含数字的字体名，排在舒圆体前面：
> `new FontFace("CuteDigits", buf, { unicodeRange: "U+0030-0039" })`，`font-family: CuteDigits, ShuYuan, Yuruka`（见 `components/theme.ts` 的 `FONT_FILES`）。
